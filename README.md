# RDKit Drug Discovery Pipeline

A Python-based cheminformatics project developed while learning RDKit for medicinal chemistry and computational drug discovery.

## Project Overview

This repository contains Python scripts for:

- Reading molecular datasets
- Calculating molecular descriptors
- Lipinski Rule of Five analysis
- Molecular fingerprint generation
- Molecular similarity search
- Compound property analysis
- Molecular visualization using RDKit
