# RDKit Drug Discovery Pipeline

A Python-based cheminformatics workflow using RDKit for molecular property calculation, drug-likeness evaluation, molecular fingerprint generation, similarity searching, and automated compound reporting.

## Features

- Molecular descriptor calculation
  - Molecular Weight
  - LogP
  - Hydrogen Bond Donors (HBD)
  - Hydrogen Bond Acceptors (HBA)

- Lipinski Rule of Five filtering

- Morgan fingerprint (ECFP4) generation

- Tanimoto similarity calculation for molecular similarity searching

- Molecular structure visualization from SMILES

- Automated compound property reporting

## Tools Used

- Python
- RDKit
- Pandas
